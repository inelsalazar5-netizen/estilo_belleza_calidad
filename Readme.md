
# Estilo & Belleza

## Descripción del proyecto
Estilo & Belleza es un sistema web desarrollado en PHP y MySQL para administrar un negocio de servicios de belleza.

El sistema permite gestionar los servicios, empleados, usuarios y citas, facilitando la administración del negocio.

## Tecnologías utilizadas
- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap
- XAMPP

## Funcionalidades principales
- Inicio de sesión de usuarios.
- Administración de usuarios.
- Gestión de servicios de belleza.
- Registro y administración de empleados.
- Gestión de citas.
- Conexión con base de datos MySQL.

## Instalación y configuración

1. Instalar XAMPP.
2. Copiar la carpeta del proyecto en `htdocs`.
3. Iniciar Apache y MySQL.
4. Entrar a phpMyAdmin.
5. Crear la base de datos `estilo_belleza`.
6. Importar el archivo `estilo_belleza.sql`.
7. Configurar la conexión a la base de datos en `config/conexion.php`.
8. Abrir el proyecto desde el navegador:

   http://localhost/estilo_belleza_calidad/
